# Preserve octave anchoring and add continuous scale degrees

The seven-white-key octave cannot represent every degree of a scale longer than seven notes while also making each physical C the octave Root. The accepted direction retains Octave Anchored for seven-note scales and adds Continuous Degrees for one to twelve distinct notes: successive white keys traverse every degree before the sounding octave advances. MIDI 60 is the reference for the selected Root, with the same sequence continuing below and above it; seven-note pitch mappings remain compatible. New devices default to Continuous Degrees. Existing version-2 Set states migrate to Octave Anchored while preserving the separately saved draft and sounding roots/memberships. A scale incompatible with Octave Anchored automatically uses Continuous Degrees with visible status instead of muting new white notes. This automatic fallback preserves the preferred mode: Octave Anchored resumes when the sounding scale has seven notes again. The same rule covers every supported non-seven-note scale. The preferred mode is saved per device; the effective mode follows the sounding scale, independently of unapplied draft edits.
